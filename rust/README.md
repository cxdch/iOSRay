# Rust-часть iOSRay

Код, который разбирает данные из файлов игры, постепенно переводится на Rust:
там ошибка с указателями превращается в случайный вылет, а Rust не даёт выйти за
границы буфера.

## texcodec

`rust/texcodec` — статическая библиотека с C-интерфейсом (`include/xr_texcodec.h`):

* `xr_bc_decode_level` — распаковка BC1–BC5 (DXT1/3/5, ATI1/2) в RGBA8. Заменила
  `glBCDecode.h`; результат побитно совпадает с прежним C++ (проверено на 8000
  случайных уровнях).
* `xr_xra_validate` — проверка заголовка файла кэша ASTC (`.xra`) до того, как по
  числам из него выделится память. Битый кэш пересжимается, а не роняет игру.

Сборка: `scripts/build_rust_ios.sh` (в CI — шаг «Rust»), тесты: `cargo test`.
