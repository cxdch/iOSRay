# Находки 13.11.2026

Проверено на OpenXRay `dev` @ `ddb78a5` (6.11.2026) и ветке TmLev `tmlev/shadow-of-chernobyl` @ `a6df2a2` (12.08.2026).

## Шейдеры: GLSL OpenXRay → MSL

286 GL-шейдеров (`res/gamedata/shaders/gl`, 199 `.ps` + 87 `.vs`), glslang 15.1 + SPIRV-Cross (master), MSL 2.1 для iOS.

| Пресет | Сконвертировано в MSL | Не собралось |
| --- | --- | --- |
| high (динамический свет R2) | **279 из 286** | 7: `fxaa.ps`, `gather.ps` — вспомогательные куски без `main`; 5 SSAO-вариантов — нужен свой набор define |
| low (`USE_R2_STATIC_SUN`) | 242 из 286 | 44: в основном `deffer_base_*` — несовпадение типов в ветке «статического солнца»; ветку для GL, похоже, никто не проверял |

- Ни один шейдер не упал на шаге SPIR-V → MSL: все проблемы — в GLSL-исходниках или наборе define.
- 14 вершинных шейдеров моделей собираются только со `SKIN_0..4` — движок так их и использует.
- Лимиты Metal не задеты: максимум 11 буферов, 11 текстур, 11 сэмплеров на шейдер.
- SPIRV-Cross делает из «свободных» uniform отдельные `constant`-буферы (`m_WVP [[buffer(0)]]`).
  Для движка нужно либо собирать их в один uniform-блок, либо строить таблицу «имя → слот» из reflection.
- 11 путей в `#include` записаны с другим регистром букв (`iostructs\p_aa_AA_combine.h`) —
  на iOS (регистрозависимая ФС) нужен поиск без учёта регистра.
- **Не проверено:** компиляция MSL драйвером Metal. Это и делает XRProbe на телефоне.

## Движок

- Рендер и игра уже линкуются статически в один исполняемый файл (`src/xr_3da/entry_point.cpp`) — `dlopen` для них на iOS не нужен.
- GL-специфичного кода немного: `xrRenderGL` + `xrRenderPC_GL` ≈ 9,8 тыс. строк. Остальное — общий слой `xrRender`/`xrRender_R2`
  (201 место с `USE_OGL`). Это и есть объём работы для `xrRender_Metal`.
- В апстриме появилась ветка `XR_PLATFORM_WEB` (114 мест): GLSL переписывается в ESSL 300 для WebGL 2.
  Запасной путь для ранней картинки на iPhone, пока нет Metal.
- SDL используется глубоко: 77 файлов, включая коды клавиш в `xrGame/ui`. **Решение: оставить SDL2 на iOS**
  (у SDL есть UIKit-бэкенд) как слой окна и событий, а Metal и сенсорный оверлей делать своими.
- Ветка TmLev для ТЧ свежая и большая (ПДА, задания, карта, анимации собак — август 2026),
  есть инструкция «ТЧ на Apple Silicon Mac» (`misc/macos/README.md`). Движок читает оригинальные
  зашифрованные `gamedata.db*` сам — распаковывать архивы не нужно.
